## Формат (правила макета)
- PNG с альфой: снаружи круга прозрачность (как KOT)
- один кантик под макет — без второго обода поверх и без сжатия арта
- Belhydromet / print-56mm: 1371×1371, 600 dpi (56 мм + 1 мм bleed)
