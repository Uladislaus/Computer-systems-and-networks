## Как сделать видимым на других устройствах

Cursor-чат **сам по себе не всегда переезжает** между ПК. Надёжная схема:

1. **Файлы** держите в одном месте, которое синхронизируется:
   - **OneDrive** (например `D:\Work\...` внутри OneDrive), или
   - **GitHub** (эта папка в репозитории) — `git pull` на другом ПК.
2. На каждом устройстве: Cursor → **File → Open Folder** → `D:\Work\Kubicheskiy-Splajn`.
3. Новый чат создавайте **уже в этой открытой папке** и ссылайтесь на `@zapiska_kubicheskiy_splajn.md`.
4. Всё важное пишите **в записку**, а не только в чат — тогда на другом устройстве контекст не пропадёт.
