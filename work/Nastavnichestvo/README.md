## Как оформить к подписи

1. Откройте `.docx` в Word, заполните поля в квадратных скобках `[...]`.
2. При необходимости подгоните под бланк Белгидромета (шапка, реквизиты).
3. Распечатайте → подписи: **наставляемый**, **наставник**, при необходимости **руководитель** / **кадры**.
4. Храните подписанный скан рядом (`scans\`).
