# Документы наставничества (приказ 154-ОД от 14.05.2026)

Локальная копия на ПК: скопируйте папку в `D:\Work\Nastavnichestvo\`.

## Файлы

| Файл | Назначение |
|------|------------|
| `01_Plan_nastavnichestva.md` | **основной документ** — план индивидуального наставничества под подпись наставника и наставляемого |
| `02_Individualnaya_programma.md` | индивидуальная программа развития (детализация по темам) |
| `03_Zhurnal_nastavnichestva.md` | журнал встреч / занятий |
| `04_Otchet_nastavnika.md` | отчёт наставника по итогам периода |
| `05_Blank_utverzhdeniya.md` | лист утверждения плана (если нужен отдельный титул) |

## Как оформить к подписи

1. Заполните поля в квадратных скобках `[...]` (ФИО, должности, подразделение, сроки).
2. Экспортируйте `01_Plan_nastavnichestva.md` в Word/ODT (или скопируйте таблицы в бланк организации).
3. Распечатайте → подписи: **наставляемый**, **наставник**, при необходимости **руководитель подразделения** / **кадры**.
4. Храните подписанный скан рядом с этой папкой (`docs\` или `scans\`).
