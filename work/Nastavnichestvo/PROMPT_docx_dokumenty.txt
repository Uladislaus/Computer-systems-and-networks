# Промпт: документы «как для кадров» (.md + .docx)

Скопируйте блок ниже целиком в новый чат Cursor (лучше Agent / Cloud, где можно ставить пакеты и писать файлы).

---

```
Сделай комплект служебных документов уровня «для печати и подписи в организации» (ГУ / отдел кадров / руководитель).

## Формат выдачи (обязательно оба)
1. Исходники в Markdown (UTF-8) — править удобно.
2. Готовые Word-файлы `.docx` в подпапке `docx/` — для печати.
   НЕ предлагай только «открой .md в Word» и НЕ оставляй меня с полусломанной вставкой.
   Конвертацию делай сам программно (предпочтительно `python-docx`):
   - шрифт Times New Roman 12 pt (заголовки 14–16, таблицы 9–11);
   - поля ~2–2.5 см;
   - markdown-таблицы → настоящие таблицы Word (Table Grid);
   - заголовки # / ## / ### сохранить иерархией;
   - списки и подписи для заполнения («____», даты, М.П. при необходимости).

## Качество оформления
- Канцелярский стиль РБ/организации: «УТВЕРЖДАЮ», основание (приказ №… от …), таблицы реквизитов, этапы, подписи.
- Плейсхолдеры только в виде [ФИО], если данных нет; если данные даны — подставить сразу.
- Без «воды», без эмодзи, без маркетингового тона.
- Документы должны выглядеть готовыми к распечатке, а не черновиком чата.

## Содержание
[ОПИШИТЕ ЗДЕСЬ: тип документов, основание/приказ, ФИО, должности, сроки, темы/этапы, что подписать]

## Проверка перед сдачей
- Открываемость .docx, кириллица на месте, таблицы не «поплыли».
- Список файлов + куда сохранить локально.
- Кратко: что заполнить человеку вручную (подписи, даты факта).
```

## Короткая версия (если мало места)

```
Сделай [тип документа] для печати: Markdown + готовый .docx через python-docx
(Times New Roman, таблицы Word, поля подписи, канцелярский стиль РБ).
Основание: [приказ]. Данные: [ФИО, должности, сроки, содержание].
Не оставляй только .md — нужен готовый .docx в docx/.
```

---

## Почему так (памятка себе)

Раньше «переведи md→docx» часто ломалось: другой чат без нормальной конвертации, Word/COM на Windows, копипаст таблиц.
Надёжный путь: **агент сам генерирует `.docx` через `python-docx`**, а `.md` держит как редактируемый исходник.
