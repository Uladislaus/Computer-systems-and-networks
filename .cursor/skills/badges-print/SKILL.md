# Значки в печать — skill из диалога

Читай этот файл **сразу**, если пользователь сбрасывает картинку значка или просит
переделать / допилить ободок / собрать zip.

Каталог соответствия картинка → файл: `badge-catalog.json` (рядом с этим SKILL.md).
Готовые файлы: `work/File/badges_print_ready/`. Скачивание: `badges.zip` там же.

## Жёсткие правила печати (не нарушать)

1. **Размер:** `1371×1371` PNG RGBA (≈56 мм + 1 мм bleed @ 600 dpi).
2. **Снаружи круга — прозрачность** (не чёрный/белый квадрат в финале).
3. **Один кантик** из макета. Запрещены: двойной ободок, белый внешний контур,
   «карточка» с прямоугольной рамкой, вложенная карта в карте.
4. **Не ужимать арт искусственно** ради пустых полей. Если нужен **более широкий**
   ободок — чуть уменьшить **всю** композицию целиком и рисовать ободок в кольце
   снаружи (картинку не обрезать по краям сцены).
5. **Не жрать светлый металл** при очистке фона: flood-fill только с краёв по
   почти-белому / чёрному квадрату / alpha&lt;10. Не снимать pale fringe с серебра.
6. **Белгидромет:** одна карта Беларуси cyan + **чисто белое** здание с двумя куполами.
   Не затемнять здание. Не дублировать карту/здание.
7. Финалы держать в git на ветке `cursor/badges-print-black-bg-f67c` и в `badges.zip`.
   Имя архива короткое: `badges.zip` (не длинные названия).

## Как понять, какой значок сбросили

Порядок распознавания:

1. **Прочитай текст на круге** (дуга сверху/снизу) → найди в `badge-catalog.json`
   по полю `text` / `text_aliases`.
2. Если текста нет — **визуальные якоря** (`visual_cues`): кот снизу сквозь стекло,
   банан, мандарины, аниме-пацаны, Nazgûl + кольцо + письмо, логотип компании и т.д.
3. Сверь с уже лежащими файлами в `work/File/badges_print_ready/`.
4. **Если это повтор уже готового** — явно скажи пользователю («это повтор X»)
   и спроси / обнови только если просят. Не молча плодить дубликаты.
5. У части значков есть **два имени**: legacy (`04_mandariny.png`) и TZ
   (`14-schastie.png`). Оба могут быть валидны; в zip клади оба, если оба нужны
   пользователю. Не выкидывай ранний пакет из zip «для стройности».

## Стили ободка (под картинку)

| Ситуация | Ободок |
|----------|--------|
| Портреты / коты / мем-фото | золото или rose-gold, один объёмный tubular bezel |
| Романтика (счастье, улыбаешься) | rose-gold / champagne, один ободок, без розового glow-ореола и без «двойного кольца» |
| Ручное наведение | тёмный оливково-бронзовый (как early pack), не яркое золото |
| Ночные сцены (идущий в реке, человек-пиздёж) | широкий яркий gold |
| Я банан | тёмный / gunmetal под чёрный фон |
| Властелин повестки | металл в тон фону логотипа (серебро / wine-copper / gunmetal); **не** ломать серебряный край alpha-маской |
| Фильмы Белгидромет | один металл в палитре сцены (железо / золото / пурпур и т.д.) |

Ширина: для печати после trim ориентир **≥ ~2–3 мм** видимого металла на 56 мм
(на 1371 px это примерно **50–80+ px** по радиусу). Тонкая «нитка» — плохо.

## Типичный пайплайн по сброшенной картинке

1. Сохранить asset, прочитать картинку, сопоставить с каталогом.
2. Сообщить: «это X → `filename`» (+ повтор или нет).
3. Если нужен только print-ready: safe circle crop + alpha (как `to_circle` в истории).
4. Если просят другой ободок: strip тонкий старый rim → scale art в inner disk →
   нарисовать **один** metal rim → финальная ellipse-mask. Проверить **нет gap**
   между rim и артом по радиусу.
5. Не чинить текст плоским белым PIL-боксом поверх (пример FK на лезвии — только
   в металле кадра / реген).
6. Обновить `badges.zip` **включая** early pack (аниме, мандарины, портреты, коты),
   не только «новую» пачку.
7. Commit + push на `cursor/badges-print-black-bg-f67c`, обновить PR.

## Чего пользователь уже отвергал (не повторять)

- Уменьшение арта + два кантика.
- Затемнённое белое здание Белгидромета.
- Карта Беларуси внутри второй карты.
- Плоский белый оверлей текста вместо гравировки/рисовки в кадре.
- Съеденный слева серебряный ободок после post-process.
- Выкидывание портретов/мандаринов/аниме из zip, хотя они есть в репо.
- «Улучшение» уже approved финала без просьбы (пример: откат белгидромет-повестки).
