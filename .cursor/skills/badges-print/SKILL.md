# Значки — что хочет пользователь на самом деле

## Неявный бриф (главное)

Если прислали **картинку** и коротко сказали «значок» / «сделай значок» /
«в печать» / «ободок» — **не спрашивай ТЗ с нуля**. Подразумевается весь стек
из нашего длинного диалога:

1. Это **круглая металлическая медалька/значок** под печать (не стикер-квадрат,
   не аватар «как есть»).
2. Нужен **готовый файл в пак**: `work/File/badges_print_ready/` + обновлённый
   `badges.zip` на ветке `cursor/badges-print-black-bg-f67c`.
3. Формат: **1371×1371 PNG**, снаружи круга **прозрачность**, **один** объёмный
   металлический ободок в цвет/настроение картинки.
4. Картинку **не корежить**: не ужимать «для красоты», не резать сюжет ободком,
   не рисовать второй кантик, не клеить плоский белый текст поверх.
5. Ободок — **акцент**: подобрать стиль под сцену (золото / rose-gold / олива /
   gunmetal / серебро…). Тонкая нитка = плохо; широкий tubular bezel = норма.
6. Если картинка уже из пака — **узнай** её и скажи («это ручное наведение /
   повтор»). Если новая — сделай по тем же правилам и положи рядом.
7. Ответ короткий по-русски + превью; детали — в git/zip.

Имена файлов (`24-ruchnoe-…`) — **вторичны**. Сначала смысл: «из этой картинки
сделай наш печатный значок как мы всегда». Каталог `badge-catalog.json` только
помогает **узнать**, что за сюжет и не задвоить работу.

## Как читать сброшенную картинку

Смотри на кадр глазами печатника:

| На картинке | Что делать |
|-------------|------------|
| Уже круг + ободок + текст | Довести до print-ready (crop/alpha/1371), подтянуть ободок если тонкий/битый |
| Квадратное фото/арт без круга | Собрать значок: круг, текст если был в ТЗ/на рефе, ободок под палитру |
| Похоже на уже готовый файл в паке | Назвать что это; обновить только если просят |
| Серия «Властелин повестки» / логотип фирмы | Кольцо + письмо + 4 силуэта, серебро по очереди, ободок в тон лого |
| Белгидромет на фильме | Одна cyan-карта, **белое** здание, один ободок |
| Пара / романтика | Rose-gold романтичный ободок, один, без розового glow |
| Ночной портрет у реки | Широкий яркий gold |
| Кот / мем | Золотой (или тёмный, если фон чёрный как «я банан») |

Текст на дуге круга — главный ключ узнавания; если текста нет — поза/фон/кот.

## Жёсткие правила (не нарушать)

1. `1371×1371` RGBA; снаружи круга alpha=0.
2. **Один** кантик. Нет двойному ободку, белому внешнему контуру, «карточке».
3. Шире ободок → слегка уменьшить **весь** круг целиком, ободок снаружи арта;
   сюжет по краям не обрезать.
4. Чистка фона: flood-fill с краёв (почти-белое / чёрный квадрат / alpha&lt;10).
   Не выедать светлое серебро.
5. Белгидромет: одна карта; здание чисто белое; без карты-в-карте.
6. Не «улучшать» уже approved финал без просьбы.
7. `badges.zip` короткое имя; **не выкидывать** из zip портреты/мандарины/аниме/котов.

## Ободки под настроение

| Сцена | Ободок |
|-------|--------|
| Портреты, коты, мемы | золото / rose-gold, tubular |
| Счастье, улыбаешься | романтичный rose-gold + champagne, один слой |
| Ручное наведение | тёмная оливковая бронза (как early pack) |
| Идущий в реке, человек-пиздёж | широкий яркий gold |
| Я банан | тёмный gunmetal |
| Повестка + логотип | металл в тон фону лого; серебро не ломать маской |
| Фильмы | один металл в палитре сцены |

Ориентир ширины: ~2–3 мм на 56 мм значке (≈50–80+ px по радиусу на 1371).

## Пайплайн по умолчанию (картинка + «значок»)

1. Открыть картинку → понять сюжет и желаемый ободок (таблица выше).
2. Если узнаётся по каталогу — назвать человекочитаемо («ручное наведение»),
   не только filename.
3. Сделать print-ready; при необходимости переделать ободок.
4. Положить в `work/File/badges_print_ready/`, обновить `badges.zip` (полный пак).
5. Commit/push на `cursor/badges-print-black-bg-f67c`.
6. Коротко ответить + превью в `/opt/cursor/artifacts/`.
