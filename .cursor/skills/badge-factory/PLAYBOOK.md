# Badge Factory — план цеха

Полный план макета и сборки. Работает с любой картинкой в любом проекте.

## Стадии

```
1. INTAKE     → принять картинку + короткую фразу
2. READ       → понять сцену, текст, настроение, нужен ли реген
3. LAYOUT     → круг, текст на дуге, один ободок, без мусора
4. ASSEMBLE   → 1371, alpha, rim (скрипт или генерация)
5. QC         → чеклист ниже
6. DELIVER    → файл / папка / zip — куда принято в этом чате
```

### 1. Intake

Триггеры: «значок», «медалька», «badge», «ободок», «в печать», «56 мм».
Картинка может быть единственным вложением — этого достаточно.

Спросить только если критично неизвестно:
- другой размер (не 56 мм);
- куда класть файл (если нет принятой папки в проекте);
- нужна ли **полная перегенерация** сюжета или только сборка/ободок.

### 2. Read (что хотел автор кадра)

Зафиксируй про себя (можно не писать пользователю длинно):

- **Сюжет:** портрет / мем / кот / фильм / лого / фэнтези-серия …
- **Текст на дуге:** есть / нет / надо сохранить дословно
- **Палитра:** тёплая / холодная / чёрная / брендовая
- **Ободок:** рецепт из `recipes/rim-palettes.json`
- **Режим:**
  - `assemble` — круг+alpha+rim из готового арта
  - `regen` — перегенерировать кадр (ободок и текст в промпте)
  - `fix` — только ободок/баг (двойной контур, съеденный металл)

### 3. Layout (законы макета)

Один круг = один значок.

Внутри круга обычно:

```
        ╭──────── текст дугой (опц.) ────────╮
       ╱                                      ╲
      │              главный сюжет              │
      │         (лицо / сцена / логотип)        │
       ╲                                      ╱
        ╰──── текст дугой снизу (опц.) ──────╯
                 ▓ металлический ободок ▓
```

Законы:

1. **Один** металлический ободок (tubular / beveled). Не два. Не белый контур снаружи.
2. Ободок — часть объекта, не рамка превью.
3. Текст либо вшит в арт, либо аккуратно по дуге; **не** белый прямоугольник поверх.
4. Логотип бренда — один экземпляр; без «карта в карте» / «лого в лого».
5. Светлые элементы бренда (например чисто белое здание) не сереть.
6. Фон снаружи круга в финале — прозрачный (в превью можно показать на чёрном).

Серия «Властелин повестки» (если продолжают):

- надпись «ВЛАСТЕЛИН ПОВЕСТКИ»;
- Кольцо + запечатанное письмо внутри;
- 4 силуэта, **один серебряный** на экземпляр по очереди;
- фон = логотип компании; ободок в тон фону.

### 4. Assemble

**A. Готовый круглый арт** → `scripts/assemble_badge.py`:

- flood-fill фона с краёв (почти-белое / чёрный квадрат / alpha);
- вписать в квадрат, resize 1371;
- ellipse mask;
- опционально: снять тонкий старый rim, inset арта, нарисовать новый rim из рецепта.

**B. Нужен новый кадр** → генерация:

- промпт: circular enamel pin, single metal rim, transparent/white outside,
  no double border, no cards; описать сюжет и текст;
- reference_image_paths если есть реф;
- после генерации — обязательно прогнать assemble (круг+alpha+1371).

**C. Шире ободок без обрезки сюжета:**

1. Снять старый тонкий rim (inner content keep ~0.96–0.97 R).
2. Crop по opaque bounds → scale в диск `inner_frac` (типично 0.87–0.90).
3. Нарисовать rim в кольце `[inner_frac .. 0.997] R`.
4. Проверить: нет gap между rim и артом по радиусу.

### 5. QC checklist

- [ ] 1371×1371 (или согласованный размер)
- [ ] Углы: alpha = 0
- [ ] Центр: alpha = 255
- [ ] Ровно один ободок, без второго контура
- [ ] Нет дырки между ободком и картинкой
- [ ] Светлый металл не почернел после post-process
- [ ] Текст читается, не «наклейка»
- [ ] Сюжет не обрезан краем ободка
- [ ] Превью на тёмном фоне выглядит как физическая медалька

### 6. Deliver

- Файл PNG; при серии — все экземпляры + короткий zip с нормальным именем (`badges.zip`).
- Contact sheet в артефакты чата, если значков несколько.
- Не удалять старые принятые финалы «для порядка», пока пользователь не сказал.

## Рецепты ободков (кратко)

| mood key | Когда |
|----------|--------|
| `gold_wide` | Ночь, драма, большинство портретов/котов |
| `rose_romantic` | Пара, счастье, «улыбаешься» |
| `olive_bronze` | Техника, хаки, «ручное наведение» |
| `gunmetal` | Чёрный фон, контрастный персонаж |
| `silver_chrome` | Sci-fi, хром; осторожно с alpha |
| `match_logo` | Серия с корпоративным фоном — взять hue фона, металл темнее/светлее |

Точные RGBA stops — в `recipes/rim-palettes.json`.

## Антипаттерны (уже обжигались)

1. Уменьшил арт + нарисовал два кантика.
2. Белый текст box поверх лезвия/металла.
3. Съел серебряный край flood-fill’ом по «бледным» пикселям.
4. Задвоил бренд-символ (карта в карте).
5. Выкинул часть готового пака из выдачи.
6. Перегенерил approved финал без запроса.
7. Тонкая золотая нитка вместо ободка «как у настоящей медальки».
