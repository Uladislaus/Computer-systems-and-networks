# Этап 04 — JS-страница

## Цель

Вынести **score** в браузер: простая страница на [[JavaScript]], где счёт видно и можно менять без перезагрузки всей «игры» как приложения — только UI-слой мини-продукта.

## Сделать

- [ ] Собрать минимальную страницу: HTML + JS (и CSS по желанию)
- [ ] Показать текущий score на экране
- [ ] Кнопки или иные действия: +очки / сброс (и при необходимости −)
- [ ] Держать состояние score в JS (пока без сервера)
- [ ] Проверить в браузере ручным сценарием
- [ ] Закоммитить файлы в `web/` (или аналог)

## Критерий готово

Страница открывается локально; score обновляется в интерфейсе сразу после действий пользователя; поведение совпадает по смыслу с консольным прототипом этапа 03.
