# Этап 00 — Git и репозиторий

## Цель

Заложить основу проекта: локальный репозиторий, связь с GitHub, понятная стартовая структура папок и привычка фиксировать шаги коммитами.

## Сделать

- [ ] Создать репозиторий (локально и на GitHub)
- [ ] Добавить `.gitignore` под Python, .NET и типичный мусор редакторов
- [ ] Набросать корневой `README.md` с одной фразой о Piston Lab
- [ ] Создать скелет папок (`python/`, `csharp/`, `web/`, `api/` — по необходимости)
- [ ] Сделать первый осмысленный коммит и push
- [ ] Зафиксировать в vault ссылку на репозиторий (в итог или в карту)

## Критерий готово

Репозиторий доступен на GitHub, структура понятна с первого взгляда, есть хотя бы один коммит с описанием «зачем», а не только «init».
