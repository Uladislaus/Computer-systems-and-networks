# Этап 03 — Score в консоли

## Цель

Ввести сущность **score** — числовой игровой счёт сессии/раунда — и научиться его менять, показывать и (на этом этапе) хранить хотя бы в памяти процесса через консольное приложение.

> **Score / очки** здесь — очки мини-продукта (game score), **не** учебные баллы.

## Сделать

- [ ] Определить минимальную модель: например `score: int`, старт с `0`
- [ ] Реализовать консольные действия: увеличить / уменьшить / показать / сбросить
- [ ] Защититься от бессмысленных значений (например, score не ниже 0 — если так решено)
- [ ] Прописать короткий сценарий ручной проверки
- [ ] Закоммитить консольный прототип

## Критерий готово

Из консоли можно пройти сценарий «старт → набор очков → показ → сброс» без падений; в коде видно отдельную сущность score, а не «магическое число в print».
