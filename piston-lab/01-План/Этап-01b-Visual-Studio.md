# Этап 01b — Установка Visual Studio (для C#)

## Цель

Поставить полноценную среду для C# / .NET, чтобы на [[Этап-02-Подсчёт-слов]] и дальше писать и запускать код на C# удобно (не только из терминала).

> VS Code / Cursor уже используются для Python.  
> **Visual Studio** (Community) — отдельно, под .NET и C#.

## Сделать

- [ ] Скачать **Visual Studio 2022 Community**: https://visualstudio.microsoft.com/downloads/
- [ ] В установщике выбрать рабочую нагрузку **«Разработка классических приложений .NET»** / **.NET desktop development** (и при желании ASP.NET — позже для API)
- [ ] Дождаться установки, перезапустить ПК при необходимости
- [ ] Проверить в новом PowerShell: `dotnet --version` (должна быть версия SDK)
- [ ] Один раз открыть Visual Studio, убедиться что стартует
- [ ] Короткая заметка в выполнении: версия VS и вывод `dotnet --version`

## Критерий готово

`dotnet --version` работает; Visual Studio открывается; можно переходить к подсчёту слов на C# после Python-части этапа 02.
