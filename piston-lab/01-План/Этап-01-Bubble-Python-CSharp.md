# Этап 01 — Bubble sort: Python и C#

## Цель

Реализовать **один и тот же** алгоритм сортировки пузырьком на [[Python]] и [[CSharp]], чтобы сравнить синтаксис, типы, запуск и стиль кода — без привязки к score и мини-продукту.

> Напоминание: bubble sort — дорожка **сравнения языков**, не игровая механика.

## Сделать

- [ ] Написать bubble sort на Python (функция + простой вывод / проверка)
- [ ] Написать bubble sort на C# (метод + простой вывод / проверка)
- [ ] Прогнать оба варианта на одном наборе входных данных
- [ ] Кратко зафиксировать различия (типы, циклы, запуск, «шум» вокруг алгоритма)
- [ ] Закоммитить реализации в репозиторий

## Критерий готово

Оба варианта корректно сортируют согласованный тестовый массив; в vault есть заметка о различиях; код лежит в репозитории.
