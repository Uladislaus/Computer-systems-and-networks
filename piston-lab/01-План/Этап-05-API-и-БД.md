# Этап 05 — API и БД

## Цель

Замкнуть контур мини-продукта: страница (клиент) обменивается со сервером через JSON, а **score** сохраняется в базе (или в согласованном persistent-хранилище на старте).

## Сделать

- [ ] Выбрать стек API (например Python или C#) и простой способ хранения
- [ ] Описать контракт JSON для score (чтение / запись)
- [ ] Реализовать эндпоинты: получить score, обновить score
- [ ] Подключить сохранение (БД или файл как временный шаг с планом замены)
- [ ] Связать [[JavaScript]]-страницу с API (fetch / аналог)
- [ ] Проверить полный путь: UI → API → хранилище → UI
- [ ] Закоммитить API, схему/миграции или инструкции запуска

## Критерий готово

После перезапуска сервиса ранее сохранённый score доступен снова; клиент и сервер говорят на одном JSON-контракте; в vault зафиксировано, как поднять систему локально.
