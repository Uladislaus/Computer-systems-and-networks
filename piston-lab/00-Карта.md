# Piston Lab — карта

**Piston Lab** — личный учебный контур: азы языков и инструментов через маленькие **доведённые до рабочего вида** проекты («как поршень»); один смысл на разных языках для ассоциаций; отдельно — роли языков и их связка (экран → сервер → данные → позже телефон/движок); всё в Git/GitHub с двух устройств; карта в Obsidian + README в репо. Цель — один раз увидеть **целый контур** простого продукта и от него осознанно свернуть в веб, игры, данные или мобилки (а не сразу собирать chess.com).

## Паспорт

| Поле | Содержание |
| --- | --- |
| **Зачем** | Научиться сам; позже можно вырастить в обучение других. |
| **Как** | Мини-проекты «как поршень»: каждый шаг уже запускается. Правило: план → выполнение → итог. |
| **Три полосы** | 1) Сравнение языков (одна задача — несколько языков). 2) Роли языков (скрипт / сайт / API / позже мобилка / движок). 3) Связи (JSON, API, БД — не «алгоритм вызывает алгоритм»). |
| **Якорь сравнения языков** | **Подсчёт слов** (строки, словарь/частоты) — главная задача «один смысл на Python, потом C#». Пузырьковая — только короткий разогрев, **не** размножать на все языки. |
| **Якорь продукта** | Сквозная тема **score / очки** — число-результат мини-действия (кликер, угадайка, позже игра). Не учебные баллы. |
| **Образ цели** | Понять устройство сложных вещей (мессенджер, chess.com, игра + модель), **не** клонировать их. |
| **Инструменты** | Git, GitHub; VS Code / Cursor (Python, JS); **Visual Studio** (C# / .NET); Obsidian. Дома основа, на работе `pull` → шаг → `push`. |
| **Память** | Obsidian: план → выполнение → итог. README: что за продукт и как запустить. |
| **Результат базы** | Виден контур; развилка в любую сторону без ощущения «учил язык в вакууме». |

## Важно не перепутать

| Якорь | Полоса | Что это |
| --- | --- | --- |
| **Подсчёт слов** | сравнение языков | одна задача на Python и C#; словари, строки, частоты |
| **Bubble sort** | разогрев (этап 01) | только циклы/if/обмен; достаточно Python; **не** тащить на каждый язык |
| **Score / очки** | мини-продукт | игровой счёт → консоль → сайт → API/БД |
