# Клиент — сервер — JSON

В Piston Lab языки встречаются не «все сразу в одном файле», а по слоям.

## Как соединяются

1. **Клиент** ([[JavaScript]] в браузере) показывает **score** и реагирует на действия пользователя.
2. **Сервер** ([[Python]] или [[CSharp]]) принимает запросы и применяет правила (что можно записать в score).
3. **JSON** — общий язык обмена: компактные объекты вроде `{ "score": 12 }` вместо «каждый слой со своим форматом».
4. **БД / хранилище** помнит score между перезапусками; сервер читает и пишет, клиент хранилище напрямую не трогает.

## Мини-схема

```text
[ Страница JS ]  --JSON-->  [ API ]  <-->  [ БД ]
       ^                      |
       +------ JSON ответ ----+
```

## Зачем это лаборатории

Так закрывается третья полоса паспорта из [[00-Карта]]: не только алгоритмы и не только UI, а связка «интерфейс ↔ контракт ↔ память».
